## Notes for Reviewer / Deployer

- `deploy.sh` executes non-destructively: it checks whether `kcc-instance1-cluster` and `kcc-instance1-sa` already exist before provisioning.
- In namespaced mode, the operator deploys the controller manager with ServiceAccount `cnrm-controller-manager-kcc-instance1-control` in namespace `cnrm-system`, bound via Workload Identity to `kcc-instance1-sa`.
- The verification step creates and validates the test `StorageBucket` `kcc-instance1-bucket` and confirms live GCP Cloud Storage reconciliation.
- `teardown.sh` handles end-to-end cleanup including the test bucket, KCC resources, namespaces, operator manifests, IAM bindings, GSA, and cluster deletion.
